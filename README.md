# PulseKRN

System Command Center for Windows: cleaner, startup manager, process control, game mode, auto-pilot and more.

**[Download the latest installer](https://github.com/Havenova-x/pulsekrn/releases/latest)**

Run `PulseKRN-Setup-vX.X.exe` and follow the installer. Updates are offered inside the app (NEWS page).

This repository only hosts releases and announcements. The source code is private.
