PULSEKRN - HOW TO EDIT THE 3 FILES  (GitHub: open file > pencil icon > edit > Commit)
Apps pick up changes at start-up, then every 3 hours.
ALWAYS paste the file into https://jsonlint.com before Commit.
JSON rules: every item inside { }, items separated by commas, NO comma after the last item/line, text in "quotes".

RELEASE ORDER:  1) run build.bat  2) upload dist\PulseKRN-Setup-vX.exe to GitHub Releases  3) upload the NEW github\latest.json LAST (replace the old one)
===========================================================================

1) latest.json  = THE UPDATE  (WRITTEN BY build.bat - do not edit it by hand)
---------------------------------------------------------------------------
"version"   New version number, e.g. "2.6.0". Apps older than this get the update prompt.
"url"       Direct download link of the installer on GitHub Releases. Must match the uploaded file name.
"sha256"    Fingerprint of the installer. build.bat calculates it and writes it for you. WRONG HASH = update refused.
"notes"     Comes from release-notes.txt (one line per note) next to build.bat.

===========================================================================

2) news.json  = BANNER (top of app) + ANNOUNCEMENTS (popups + News page)
---------------------------------------------------------------------------
"banner"         null = no banner.  Or one item (fields below). User can close it with X; it returns only with a NEW id.
"announcements"  List of items. Each pops up when the app window is open (never while gaming) and is listed on the News page.

ITEM FIELDS
id           REQUIRED. Unique name, e.g. "2026-11-sale". Change it to show the item again.
title        Heading (max ~90 chars).
body         Message (max ~700 chars).
date         Text shown next to the title, e.g. "2026-11-02". Display only.
level        "info" (blue) | "important" (orange) | "promo" (green)
show         "once" (default) | "daily" (once a day) | "launch" (every app start).
             daily/launch get a "Don't show again" button.
popup        false = News page only, no popup. (default true)
link         Optional. Must start with https://
link_label   Button text, e.g. "VISIT".
link_title   Link preview title.
link_desc    Link preview description.
image        Optional https picture (PNG/JPG, under 1.5 MB) shown in the popup.
starts       "2026-11-01" = hidden before this day.
expires      "2026-11-30" = hidden after this day. Use it so old items clean themselves.
min_version  Only this version or newer sees it.
max_version  Only this version or older sees it. e.g. "2.3.1".

===========================================================================

3) ads.json  = FEATURED STRIP (slim bar at the bottom, visible while an item exists)
---------------------------------------------------------------------------
Format:  { "ads": [ { item }, { item } ] }      Several ads rotate every ~12 seconds.
Empty list { "ads": [] } = strip disappears completely.

Uses the same item fields as news.json:
id (required), title, body, date, level, link, link_label, link_title, link_desc, image,
starts, expires, min_version, max_version.
NOT used for ads: show, popup (news.json only).

HIDE AN AD: set "expires" to a past date, push "starts" into the future, or delete the item.
ADD AN AD: copy a whole { ... } block, add a comma between blocks, give it a NEW id.

===========================================================================
IMPORTANT
- Wrong or missing "id" = item ignored.  Links not starting with https:// are ignored.
- Changing "id" makes an item count as brand new (popups show again, closed banners return).
- Dates are always YYYY-MM-DD.  "expires" still shows ON that day, hides the day after.
